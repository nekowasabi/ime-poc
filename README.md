# IME POC (Input Method Editor Proof of Concept)

macOSネイティブアプリで日本語入力メソッドの候補をカスタマイズするPoCプロジェクトです。

## 機能

- 日本語入力中に「てすと」という候補を追加表示
- 選択した候補をアクティブなエディタに挿入
- 既存のIME（Google日本語入力など）の機能を妨げない
- オーバーレイウィンドウ方式による実装

## 技術仕様

- **開発言語**: Swift 5.9
- **対応OS**: macOS 12.0以降
- **フレームワーク**: AppKit, Carbon, CoreGraphics, ApplicationServices
- **アーキテクチャ**: オーバーレイウィンドウ方式

## セットアップ

### 前提条件

- macOS 12.0以降
- Xcode 14.0以降
- Swift 5.9以降

### ビルド方法

```bash
# プロジェクトのクローン
git clone https://github.com/nekowasabi/ime-poc.git
cd ime-poc

# ビルド
swift build

# リリースビルド
swift build -c release
```

### テスト実行

```bash
swift test
```

## 実行方法

### 1. アクセシビリティ権限の設定

初回実行時、アプリケーションにアクセシビリティ権限を付与する必要があります：

1. システム環境設定 → セキュリティとプライバシー → プライバシー → アクセシビリティ
2. ime-pocを追加して権限を付与

### 2. アプリケーションの起動

```bash
./.build/debug/ime-poc
```

または、リリースビルドの場合：

```bash
./.build/release/ime-poc
```

### 3. 使い方

1. アプリケーションを起動すると、メニューバーに「IME」アイコンが表示されます
2. 任意のテキストエディタ（VSCode、Xcode等）で日本語入力を開始
3. 「てすと」「tesuto」「test」のいずれかを入力すると、候補ウィンドウに「てすと」が表示されます
4. 矢印キーで候補を選択し、Enterキーで確定

## アーキテクチャ

### コンポーネント構成

- **AppDelegate**: アプリケーションのライフサイクル管理
- **InputMonitor**: グローバルキーイベントの監視
- **OverlayWindowController**: オーバーレイウィンドウの管理
- **CandidateListView**: 候補リストの表示

### 動作原理

1. `InputMonitor`がグローバルキーイベントを監視
2. 日本語入力状態を検出すると、入力文字を収集
3. `OverlayWindowController`が候補ウィンドウを表示
4. ユーザーが候補を選択すると、`Accessibility API`を使用してテキストを挿入

## 制限事項

- macOSのアクセシビリティ権限が必要
- 一部のアプリケーションでは正常に動作しない可能性があります
- 現在は「てすと」という候補のみをサポート

## トラブルシューティング

### アプリケーションが起動しない

- アクセシビリティ権限が付与されているか確認してください
- macOSのバージョンが12.0以降であることを確認してください

### 候補が表示されない

- 日本語入力モードになっているか確認してください
- 対象のアプリケーションがテキスト入力をサポートしているか確認してください

### テストが失敗する

テストはグラフィックコンテキストを必要としないように設計されています。UI関連のテストは実際のアプリケーション実行時にのみ動作します。
